# ロジック仕様

## UI由来ルール（未確定）

Step4 で UI を作りながら決めたルール。Step6 で確定ルールに移す。

- タイトルが空（空白のみを含む）のタスクは追加できない。追加を押すとタイトル欄にエラーを表示する。
- 読み込み中はタスク一覧の代わりにスケルトンを表示し、追加フォームと件数は表示しない。
- 読み込みに失敗した場合はエラーと再読み込みボタンを表示する。再読み込みで取得をやり直す。
- 操作中（追加・完了の切替・削除）は対象の操作を無効化し、二重操作を防ぐ。追加中は「追加中...」、削除中は「削除中...」と表示する。
- 操作に失敗した場合はタスク一覧の上部にエラーを表示し、閉じるボタンで消せる。追加に失敗したときは入力内容を保持する。
- 追加に成功した後は、続けて入力できるようにタイトル欄へフォーカスを戻す。
- 新しく追加したタスクは、未完了一覧の先頭に表示する。
- 未完了タスクと完了済みタスクを分けて表示し、完了済みは下部のセクションにまとめる。並び順はデータの順序に従う。
- 完了済みタスクのチェックを外すと、未完了一覧に戻る。
- 完了を切り替えた後は、同じタスクのチェックボックスにフォーカスを戻す。
- 削除が完了した後は、タスク一覧の見出しにフォーカスを移す。
- ヘッダーには未完了数と完了数を表示し、タスク一覧の見出しには未完了数を表示する。
- 期限は任意。日付のみを指定し、`YYYY/MM/DD` 形式で表示する（P4 で確定）。
- 優先度は「高・中・低」の3段階。初期値は「中」（P4 で確定）。
- 削除は確認ダイアログで「削除する」を選んだときに確定する。キャンセル・Escape・背景クリックでは削除しない。
- 期限切れの強調表示は現時点では行わない（Step6 で決める）。
