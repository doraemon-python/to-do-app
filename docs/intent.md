# ユーザー意図

## 目的と解決したい課題

個人のタスクをブラウザ上で管理するための、シンプルな ToDo アプリ。タスクをすぐ追加でき、期限と優先度を見ながら完了・削除できる。

## 想定ユーザーと利用シーン

- 想定ユーザー: 自分1人
- 利用シーン: PC の作業中に、思いついたタスクを追加する。期限と優先度を確認しながらタスクを片付け、不要なものは削除する。データは同じブラウザ内に保存され、次回も続きから使える。

## ユーザーの思想・こだわり

- 自分だけが使う個人用ツールにする
- 機能は必要最小限（追加・完了・削除、期限、優先度）に絞る
- データは端末内で完結させ、外部サービスに送らない
- シンプルで迷わない操作感を優先する

## 制約

- ブラウザ内保存のため、別の端末やブラウザとは同期しない
- サーバー・認証は不要
- PC 中心の利用（スマホ向けの最適化は行わない）

## 非機能要件

| 項目           | 回答                                                                         |
| -------------- | ---------------------------------------------------------------------------- |
| 想定ユーザー数 | 1人（自分だけ）                                                              |
| 認証           | 不要                                                                         |
| データの機密性 | 個人データ。ブラウザ内のみに保存し、外部送信しない                           |
| 対応デバイス   | PC 中心                                                                      |
| オフライン対応 | 不要（サーバー通信を行わない構成のため、初回読み込み後はローカルで動作する） |
| その他         | 多言語対応・外部システム連携・公開予定はなし（個人用・ローカル利用のため）   |

## 用語集

| 用語   | 意味                                                                  | 出典（回答日／資料）                                    |
| ------ | --------------------------------------------------------------------- | ------------------------------------------------------- |
| ToDo   | ユーザーが管理する1件のタスク。タイトル、期限、優先度、完了状態を持つ | 2026-11-13 回答（「追加・完了・削除」「期限・優先度」） |
| 期限   | ToDo をいつまでに終えたいかを示す情報                                 | 2026-11-13 回答（「期限・優先度」）                     |
| 優先度 | ToDo の重要度。段階の詳細は UI 提案で確認する                         | 2026-11-13 回答（「期限・優先度」）                     |
| 完了   | ToDo が終わった状態                                                   | 2026-11-13 回答（「追加・完了・削除」）                 |
| 削除   | ToDo を一覧から取り除くこと                                           | 2026-11-13 回答（「追加・完了・削除」）                 |

## ドメインのロジック

- ToDo は「追加・完了・削除」の3操作で管理する。
- 期限と優先度は ToDo に付与できる。
- 並び順、期限切れの扱い、完了済みの表示方法、優先度の段階、期限の入力形式は、UI を見ながら `docs/open-questions.md` で決める。
